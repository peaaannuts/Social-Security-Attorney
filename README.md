# 社労士 一問一答（個人開発版）

社会保険労務士試験の学習用 PWA。スマホのスキマ時間に、一問一答（○×）＋間隔反復＋科目別の弱点可視化で「解きっぱなし」を防ぐ、自分専用の学習ツールです。

要件定義: [`要件定義書`](#) に基づく MVP（F-1〜F-4）実装。

## コンセプト

- **起動から演習開始まで3タップ・5秒以内**（ホームの「今日の復習」or「全科目ランダム」を1タップ）
- **1セッション5〜10問**で完結。中断されても学習は壊れない
- **忘却曲線ベースの出題**（簡易 SM-2）で復習を自動スケジュール
- **オフライン動作**（データはブラウザの IndexedDB にローカル保存。地下鉄でも演習可）
- **片手・親指のみ**で全操作完結。ダークモード既定

## 実装済み機能（MVP）

| 機能 | 内容 |
|---|---|
| **F-1 一問一答演習** | ○×形式。1問1画面、タップで即判定→解説表示。「自信なし」フラグ対応。出題モード: 科目指定 / 全科目ランダム / 復習 |
| **F-2 問題データ管理** | CSV / JSON インポート、アプリ内での追加・編集・削除 |
| **F-3 復習キュー（間隔反復）** | 正誤・自信なしに応じて次回出題日を自動決定（簡易 SM-2）。ホーム最上部に「今日の復習 ○問」を常時表示 |
| **F-4 学習記録・弱点可視化** | 科目別正答率（足切りリスクを⚠️表示）、直近14日の学習量、タグ別正答率、連続学習日数 |
| **データ保全** | 学習履歴を含む全データの JSON バックアップ書き出し／復元 |

科目: 労基・安衛 / 労災 / 雇用 / 徴収 / 労一 / 社一 / 健保 / 国年 / 厚年

> 初回起動時に、条文（公表資料）ベースの自作サンプル問題を約20問投入します。市販教材の転載は含みません。

## 技術構成

- **React + TypeScript + Vite**
- **Tailwind CSS v4**（`@tailwindcss/vite`）
- **Dexie.js**（IndexedDB ラッパー）でローカル永続化
- **vite-plugin-pwa**（Service Worker / オフラインキャッシュ / ホーム画面追加）
- サーバーレス。認証・アカウント管理なし（自分ひとり用）

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # 型チェック + 本番ビルド（dist/）
npm run preview    # ビルド結果をローカルプレビュー
npm run typecheck  # 型チェックのみ
```

スマホ実機で試すには、同一 Wi-Fi 上で `npm run dev -- --host` を実行し、表示される
`http://<PCのIP>:5173` をスマホのブラウザで開きます（PWA として「ホーム画面に追加」可能）。

## デプロイ（GitHub Pages）

`main` ブランチへの push で `.github/workflows/deploy.yml` が自動ビルド・デプロイします。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定
2. `main` に push（プロジェクトページ配信のため `BASE_PATH=/<repo名>/` を CI が自動設定）
3. 公開 URL をスマホで開き、ブラウザメニューから「ホーム画面に追加」

Cloudflare Pages 等の静的ホスティングでも動作します（ルート配信なら `BASE_PATH` は不要）。

## データのインポート形式

### CSV（[`sample-questions.csv`](./sample-questions.csv) 参照）

ヘッダ行必須。列: `subject, format, questionText, answer, explanation, source, tags`

- `subject`: 上記9科目のいずれか
- `format`: `ox`（○×）※選択式 `select` はフェーズ2予定
- `answer`: `○` / `×`（`O`/`X`/`正`/`誤` 等も自動正規化）
- `tags`: `、` `,` `|` 区切り（例: `数字要件|法改正`）

PC 側で問題を作成 → CSV/JSON をアプリの「データ」画面から取り込む運用を想定しています。

## バックアップ運用

端末故障・ブラウザデータ消去に備え、**週1回**「データ」画面から
バックアップ（JSON）を書き出してください。復元も同画面から行えます。
